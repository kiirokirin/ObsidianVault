# Obsidian Git コンフリクト解決 手引書

## 1. コンフリクトとは

複数のデバイス（例：デスクトップとノートパソコン）で同じノートを編集した際、 Obsidian Git プラグインが変更内容を自動でマージできず「競合（コンフリクト）」 が発生することがあります。

このとき、Vault内に以下のような案内ファイルが自動生成されます。

```
# Conflicts
Please resolve them and commit them using the commands
`Git: Commit all changes` followed by `Git: Push`
(This file will automatically be deleted before commit)

- [[ノート名]]
```

また、実際に競合したノートには以下のようなマーカーが挿入されます。

diff

```diff
<<<<<<< HEAD
    このパソコン（ローカル）での変更内容
=======
    もう一方のデバイス／クラウド（リモート）側の変更内容
>>>>>>> origin/main
```

---

## 2. 解決の3ステップ（基本フロー）

1. **正しく整理する** 衝突しているノートを開き、不要な内容と記号（`<<<<<<<`、`=======`、`>>>>>>>`） をすべて手動で削除する。
2. **コミットする** コマンドパレット（`Ctrl+P` / Mac: `Cmd+P`）→ `Git: Commit all changes`
3. **プッシュする** コマンドパレットを再度開き → `Git: Push`

この3ステップでGit側に「コンフリクトは解消済み」と認識され、以降の同期も スムーズに進みます。

---

## 3. 詳細手順

### STEP 1｜ソースモードに切り替える

- 衝突しているノートを開く
- 画面右上、またはコマンドパレットから **「ソースモード（Source mode）」** に切り替える
- ※ Live Preview（通常表示）だと競合記号が隠れて編集しづらいため

### STEP 2｜不要な記述を削除して統合する

ノート内に以下のような形式で、ローカルとリモートの変更が並んでいます。

diff

```diff
<<<<<<< HEAD
    ローカル側の内容
=======
    リモート側の内容
>>>>>>> origin/main
```

- どちらの内容を残すか（あるいは両方を組み合わせるか）を判断する
- 残したいテキストだけを残し、記号3種（`<<<<<<<` / `=======` / `>>>>>>>`）を すべて削除する
- ファイルを保存する

### STEP 3｜コミットする

1. `Ctrl+P`（Mac: `Cmd+P`）でコマンドパレットを開く
2. `Git: Commit all changes` と入力して実行
3. この時点で、案内ファイル（Conflicts.md 等）は自動的に削除される

### STEP 4｜プッシュする

1. 再度コマンドパレットを開く
2. `Git: Push` と入力して実行
3. エラーが出なければ完了

---

## 4. 再発を防ぐコツ

- デバイス間で編集するときは、前の同期が完全に終わるのを待ってから次の編集を始める
- 同時に同じノートの同じ箇所を複数デバイスで編集しない
- 頻繁に競合する場合は、有料の **Obsidian Sync** への切り替えも検討する

---

## 5. どうしても解決できない場合

手動での統合が難しい・大量にコンフリクトしてしまった場合は、 どちらか片方のデバイスの内容で完全に上書き（強制同期）する方法もあります。 その場合は、優先したいデバイス（ローカル／リモートのどちら）を決めた上で 強制上書き用のGitコマンドを使用します。
