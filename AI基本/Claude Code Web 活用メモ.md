■ Claude Code Webとは  
Claudeに仕事を依頼し、バックグラウンドで作業させる仕組み。  
通常チャット：指示→回答→再指示  
Claude Code Web：指示→放置→成果物完成  
用途：ブログ記事、動画台本、マニュアル、レポート、調査資料

■ 最重要：Cloud.md  
Claudeが作業前に毎回読む設定ファイル。  
例：  
・結論から書く  
・親しみやすい文章  
・専門用語は解説する  
・箇条書きを使う  
・見出しを細かく入れる  
ここに書いたルールが毎回適用される。

■ AIを育てる方法①  
過去記事を複数入れて、  
「私の記事を分析し、特徴を再現できるCloud.mdを作成してください」  
と依頼する。  
分析対象：  
・文体  
・語尾  
・説明方法  
・構成  
・比喩  
・読者への語りかけ  
結果：自分専用ライターAIになる。

■ AIを育てる方法②  
修正依頼を出す。  
例：  
・もっと簡潔に  
・導入を短く  
・具体例を増やして  
さらに  
「今回の学びをCloud.mdへ反映してください」  
と指示する。  
次回以降の出力に反映される。

■ 品質向上のコツ  
いきなり執筆させない。  
まず「構成だけ作ってください」と依頼。  
例：

1. AIとは
2. メリット
3. 導入方法
4. 注意点
5. まとめ  
    構成確認後に「執筆開始」と指示する。  
    これだけで品質が大幅向上する。

■ 検索を利用する  
許可したサイトのみ検索可能。  
例：  
note.com  
zenn.dev  
qiita.com  
依頼例：  
「AIエージェントについて調査して記事を書いてください」  
リサーチと執筆を同時に実行できる。

■ スマホ運用  
スマホから依頼→放置→帰宅後レビューが可能。  
PCを起動したままにする必要はない。

■ 動画の結論  
AIに丸投げしない。  
人間が担当：  
・目的  
・読者  
・構成  
・伝えたい内容  
AIが担当：  
・調査  
・肉付け  
・執筆  
・推敲  
理想は「構成は人間、文章化はAI」。
