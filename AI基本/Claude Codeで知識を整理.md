Claude Code Web（文書作成向け）重要ポイントまとめ

■ 何ができる？  
・Claude CodeをWebブラウザから使える  
・記事作成、資料作成、リサーチを自動化できる  
・スマホから仕事を依頼できる  
・自分専用の執筆AIを育成できる

■ 必要なもの  
・Claude有料プラン  
・GitHubアカウント  
・GitHubリポジトリ

■ 基本的な流れ

1. Claude Code Webを開く
2. GitHubリポジトリを接続
3. 「○○の記事を書いて」など依頼
4. AIが作業
5. 完成後にレビュー
6. 修正指示
7. 問題なければマージ

■ 一番重要：Claude.md  
Claude Codeが毎回読む設定ファイル。

ここに

・文章の書き方  
・口調  
・構成ルール  
・禁止事項  
・リサーチ方法

などを書いておく。

つまり

「自分専用AIの人格ファイル」

みたいなもの。

■ 執筆AI育成法①  
過去記事を読み込ませる

過去に自分で書いた記事を

articles/

フォルダへ入れる。

その後、

「私の記事を分析して執筆ルールをClaude.mdに作成して」

と指示。

すると自分の文章の特徴を抽出してくれる。

■ 執筆AI育成法②  
フィードバック学習

例えば

・もっと親しみやすく  
・専門用語を減らして  
・結論を先に

など修正指示を出す。

さらに

「この学びをClaude.mdへ反映して」

と指示。

これを繰り返す。

結果

AIがどんどん自分好みになる。

■ 執筆品質を上げるコツ

AIにいきなり本文を書かせない。

先に

「構成だけ作って」

と依頼。

構成をレビュー。

OKなら

「本文を書いて」

と進める。

これだけで品質がかなり上がる。

■ Claude.mdに追加したいルール

執筆前に必ず構成を提示すること。  
構成の承認後に本文を書くこと。  
結論を先に書くこと。  
専門用語は説明すること。  
見出しは簡潔にすること。  
箇条書きを活用すること。

■ リサーチ機能

Claude Code WebはWeb検索可能。

ただし勝手に全サイトへアクセスできない。

許可したドメインだけ検索できる。

例

note.com  
zenn.dev  
qiita.com

など。

■ リサーチ記事作成例

「Opalについて調査して解説記事を書いて」

↓

AIが検索

↓

記事作成

↓

参考URL一覧も出力

■ スマホ運用

出勤前

「この記事を書いて」

↓

AI作業

↓

帰宅後レビュー

という使い方が可能。

■ 動画の核心

AIに文章を書かせること自体は誰でもできる。

差が付くのは

「Claude.mdを育てること」

である。

Claude.mdが育つほど、

毎回細かく説明しなくても

自分好みの文章を出す専属ライターになる。
