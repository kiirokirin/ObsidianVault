「非エンジニアがAIコーディングエージェントを始めるなら何がおすすめか？」

というテーマです。

結論から言うと、次の3段階がおすすめです。

1. アンチグラビティ
2. Claude Code
3. Claude CodeとCodexの使い分け

この順番がおすすめな理由を解説します。

---

# 主要なAIコーディングツール

現在、主要なツールは次の4つです。

- アンチグラビティ
- Claude Code
- Cursor
- Codex

## ツールの形態

AIコーディングツールには大きく4種類あります。

### エディター型

コード編集画面にAIが統合されているタイプ。

例：

- アンチグラビティ
- Cursor

特徴：

- ファイル閲覧
- 編集
- AIチャット

が1つの画面で完結します。

---

### 拡張機能型

VS Codeなどに追加するタイプ。

特徴：

- 既存エディターを活用可能
- 使用感はエディター型に近い

---

### デスクトップアプリ型

専用アプリとして動作。

特徴：

- セットアップが簡単
- ターミナル知識が少なくて済む

---

### CLI型

黒い画面（ターミナル）で操作するタイプ。

特徴：

- 最も高機能
- 最も難しい

---

# アンチグラビティ

Google製のAIコーディングエディター。

## メリット

- 無料
- Googleアカウントだけで開始可能
- セットアップが非常に簡単
- GeminiやClaude系モデルが利用可能
- 高性能画像生成も利用可能

## 向いている人

- AIコーディング初心者
- 非エンジニア
- とりあえず試したい人

---

# Claude Code

Anthropic社のツール。

月額20ドル程度から利用可能。

## 特徴

- コーディング性能が高い
- 計画を立ててから実装できる
- サブエージェント機能
- スキル機能
- VS Code連携
- デスクトップ版あり

## 印象

Claudeは比較的会話が丁寧です。

- 指示を理解しやすい
- 補足説明が多い
- 作業速度も速い

初心者にはかなり扱いやすい部類です。

---

# Codex

OpenAI製のコーディングエージェント。

ChatGPT Plus契約で利用可能。

## 特徴

- 技術的に強い
- 設計能力が高い
- バグが少ない
- レビューが得意

## 印象

Claudeより職人気質です。

- 会話は少なめ
- 技術的な質問が多い
- 厳密な確認をする

その代わり最終成果物の品質は高い傾向があります。

---

# Cursor

AI搭載エディターの先駆者。

## 特徴

- ブラウザ内蔵
- デザイン編集機能
- 複数AI比較機能

など独自機能があります。

ただし現在は、

- Claude Code
- Codex

の勢いが非常に強く、初心者への優先度はやや下がっています。

---

# おすすめの始め方

## 第1段階：アンチグラビティ

理由：

- 無料
- 簡単
- 導入障壁が低い

まずはAIコーディングに慣れる。

---

## 第2段階：Claude Code

理由：

- 説明が丁寧
- 初心者向き
- 実用レベルの開発が可能

AIとの協業を学ぶ段階。

---

## 第3段階：Claude Code + Codex

上級者になると使い分けが見えてきます。

### Claude向き

- 要件定義
- アイデア出し
- 実装
- ドキュメント作成

### Codex向き

- 設計
- コードレビュー
- 難しい問題解決
- 品質向上

両方を使うことで効率が大きく向上します。

---

# 開発者の実態

現在、本職エンジニアの間では、

- Claude Code
- Codex

の2強状態です。

Cursorも人気がありますが、最近はやや押され気味。

アンチグラビティは、

「無料で始める入口」

として非常に優秀ですが、メイン開発環境として使う人はまだ少数派です。

---

# まとめ

非エンジニアにおすすめの順番は次の通りです。

**Step 1**  
アンチグラビティ

↓　

**Step 2**  
Claude Code

↓

**Step 3**  
Claude CodeとCodexを使い分ける

まずは無料でAIコーディングを体験し、その後Claude Codeで本格利用へ進み、最終的にはClaudeとCodexそれぞれの得意分野を理解して使い分けるのがおすすめです。
