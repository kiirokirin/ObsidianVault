**Stripe（ストライプ）の課金システム**は、初期費用・月額費用が無料で、決済成功時のみ手数料が発生する売上連動型の決済プラットフォームです。

---


Stripe：  
自分のWebサービスに決済機能を組み込みやすい。

PayPal：  
PayPalの決済画面を使って支払ってもらう形が基本。

なので、ざっくり言えば、

「簡単に支払いを受けたい」→ PayPal

「自分のサービスに本格的な課金システムを組み込みたい」→ Stripe

---

- **都度課金（Checkout / Payment Intents）**

- **定期課金（Billing）**
  - SaaSや会員制サイトの月額・年額サブスクリプション。

- **請求書決済（Invoicing）**
  - BtoB取引向けに、PDF請求書をメール自動送付してカード決済。

**2. 料金体系と手数料**

初期費用・月額固定費・振込手数料はすべて **0円** です。

| **決済手段手数料（日本国内）備考**        |                 |                              |
| -------------------------- | --------------- | ---------------------------- |
| **主要クレジットカード**             | **3.6%**        | Visa, Mastercard, JCB, Amex等 |
| **Apple Pay / Google Pay** | **3.6%**        | スマホの生体認証で高速決済                |
| **銀行振込（自動照合）**             | **1.5%**        | 国内専用、1回の上限990円               |
| **コンビニ決済**                 | **3.4% + 150円** | ローソン、ファミマ等                   |
| **ペイディ（あと払い）**             | **3.9%**        | 分割払いにも対応                     |

**4. 2つの導入ルート**

- **ノーコード（非エンジニア向け）**
  - **Payment Links**: 管理画面で商品名と価格を入力するだけで決済URLを発行。SNSやメールで共有して即販売可能。
- **ローコード / フルコード（開発者向け）**
  - **Stripe Checkout**: Stripeが用意したセキュアな決済ページへリダイレクト。数行のコードで実装可能。
  - **Elements**: 自社サイトのデザインに完全に馴染むカスタム決済フォームをパーツ単位で構築。
