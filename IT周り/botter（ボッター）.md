**「売買を自動でやってくれるプログラムを作る人」**です。

例えば、

「価格が100万円以下 → 買う」  
「105万円になった → 売る」

というルールをPythonなどで作ります。

Botが自動で、

**価格を見る → 判断する → 注文する → 結果を確認する**

を24時間繰り返します。

つまり、

**Botter = 投資のルールをプログラムにして、自動売買する人**

です。

なお、必ずしも高速取引をするわけではありません。

---


**1. botter（ボッター）とは？**

botterとは、暗号資産（仮想通貨）や株、FXなどの金融市場において、**24時間自動で売買を行うプログラム（Bot）を自作して運用する個人開発者・投資家**のことです。
人間の感情を排除し、事前に決めたルールやアルゴリズムに従って、ミリ秒（1000分の1秒）単位の超高速取引や、膨大なデータの監視を自動で実行します。

**2. 基本的なシステムの仕組み**

Botは主に以下の3つのステップを繰り返して動いています。

- **データの取得（Public API）**
  - 取引所から「板情報（注文状況）」や「歩み値（過去の約定データ）」、チャートの価格データをリアルタイムで取得します。
- **シグナルの判定（ロジック）**
  - 集めたデータをプログラム（主にPython）で分析し、「今が買いか、売りか」を計算します。
- **注文の発注（Private API）**
  - 売買シグナルが出たら、取引所のサーバーに「買い」「売り」の注文を自動で送信します。

**3. 主な取引戦略（ロジックの例）**

botterが利益を狙うために使う代表的な手法です。

- **高頻度取引（HFT / スキャルピング）**
  - 1秒間に何十回、何百回と注文を出し入れし、数円〜数十円の微小な価格変動から利益を積み重ねます。
- **マーケットメイク（MM）**
  - 買値と売値の注文を同時に板に並べ、その「価格差（スプレッド）」を利益として獲得する手法です。
- **アービトラージ（裁定取引）**
  - 異なる取引所間、または同じ取引所の「現物」と「先物」の価格差を監視し、安い方で買って高い方で売るリスクの低い手法です。
- **トレンドフォロー / アノマリー**
  - テクニカル指標（移動平均線など）を使ってトレンドに乗る手法や、「特定の時間帯に価格が上がりやすい」といった市場の癖（アノマリー）を突く手法です。

**4. 必要なスキルと環境**

- **プログラミング言語**: 豊富なライブラリがある**Python**が主流です。速度を重視するbotterはRustやGo、C++を使うこともあります。
- **実行環境**: 自宅のPCではなく、24時間安定して稼働し、取引所サーバーとの物理的距離が近く通信速度が速い**AWS（Amazon Web Services）などのクラウドサーバー（VPS）**を利用するのが一般的です。
